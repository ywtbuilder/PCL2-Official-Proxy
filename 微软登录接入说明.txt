微软正版登录接入说明

当前状态
本修改版保留 PCL 的微软设备代码登录流程，Client ID 由本机配置文件或环境变量提供。
Client ID 是软件的应用编号，微软账号密码由用户在微软官方网页中输入。
填写了编号只表示已配置；必须完成微软登录和 Minecraft 游戏服务验证后，才能确认可用。

本分支的启动要求
完整游戏仅使用微软正版账号，不提供未验证的离线、统一通行证或 Authlib-Injector 启动方式。
该要求由实际启动登录流程执行，不依赖实例中保存的登录方式选项。
有效缓存仅用于复用尚未过期的令牌；仍查询官方 Java 版许可，并取得当前玩家资料后才继续启动。
许可检查接受 game_minecraft 或 product_minecraft，其他游戏或不相关商品的许可不会视为 Java 版许可。
许可或玩家资料查询失败时，启动流程中止；导出启动脚本也经过同一登录流程。
登录和许可请求使用 .NET 默认的 HTTPS 证书校验，不提供跳过证书错误的开关。
游戏下载、来源选择以及本机代理配置按原分支设置运行。

一、注册微软应用
打开 https://entra.microsoft.com/ ，登录后进入“Entra ID → 应用注册 → 新注册”。
名称：PCL2 Official Proxy（个人修改版）。
支持的账户类型：仅个人 Microsoft 帐户。
重定向 URI：留空。本分支采用设备代码登录流程。
注册完成后复制“应用程序（客户端）ID”，不要复制“对象 ID”或“目录（租户）ID”。
进入该应用的“Authentication (Preview) → 设置”，开启“允许公共客户端流”，保存。
该设备代码流程不需要客户端密码（Client secret）。
如果无法进入应用注册、没有目录或没有注册权限，先记录页面提示，不要把一个随机 UUID 当作应用编号。

二、Minecraft 游戏服务接入
微软应用注册与 Minecraft 游戏服务接入是不同的步骤。
取得 Client ID 后，访问 Mojang 的申请入口 https://aka.ms/mce-reviewappid ，按表单要求提交自己的应用信息。
申请中说明这是基于 PCL 公开源码的个人修改版，使用微软设备代码流程登录，仅读取拥有的游戏资料并启动游戏。
本项目仓库：https://github.com/ywtbuilder/PCL2-Official-Proxy （当前为私有仓库）。
如果表单要求可访问的源码或项目链接，需要提供审核人员能够访问的资料；本说明不代表已提交或通过审核。
不要仅凭微软授权页面能够打开，就判断 Minecraft 服务已经允许这个 Client ID。

三、在本机填写 Client ID
退出这个修改版 PCL。
用文本编辑器打开 EXE 旁边的“Plain Craft Launcher 2.exe.config”。
找到下面这一项，只将 value 的空字符串换成申请得到的 Client ID：
    <add key="PCL_MS_CLIENT_ID" value="" />
保存后重新启动 EXE，不需要重新编译。
源码中的对应配置为“Plain Craft Launcher 2\App.config”；本机实际使用时修改 EXE 旁边的配置文件即可。
原有 PCL_MS_CLIENT_ID 环境变量仍优先于配置文件；本机之前没有配置这个变量。

四、实际登录验证
在修改版 PCL 中选择“正版”登录，按提示打开微软提供的授权网页并完成登录。
确认 PCL 能够取得 Minecraft 的玩家名称、UUID 和游戏资料，再尝试启动已拥有的 Java 版游戏。
如果在第 4 步返回 HTTP 403，且服务器内容为 Invalid app registration，应核对 Client ID 与 Minecraft 游戏服务的接入审核状态。
本分支会针对这个错误显示应用注册未获接受的提示；其他 403 也不再直接判定为 IP 异常。
网页登录成功后，还需要依次通过 Xbox 和 Minecraft 服务；网页成功本身不能证明已取得 Minecraft 玩家资料。
具体登录结果以本机日志和服务返回为准。

CurseForge 可以稍后补充
原版游戏文件下载不需要 CurseForge API Key。
需要其模组服务时，按官方申请说明申请 Key：
https://support.curseforge.com/support/solutions/articles/9000208346-about-the-curseforge-api-and-how-to-apply-for-a-key
取得 Key 后，在同一 .exe.config 中填写 PCL_CURSEFORGE_API_KEY，保存并重启。
PCL_CURSEFORGE_API_KEY 环境变量仍然优先。配置文件为 XML，值内的 &、<、" 分别写成 &amp;、&lt;、&quot;。
